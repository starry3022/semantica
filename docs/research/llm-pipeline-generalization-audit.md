# LLM 链路：代码约束与跨材料适用性审计

日期：2026-09-21。范围：本次修改的语义覆盖复核 staged-v4、溯源声明 v5、
candidate facts 入口及相关图展示代码。本文是本地代码审计，不是新的厂商机制调研，
也不声称 Semantica 整个代码库不存在其他规则提取器。

## 结论

没有发现本次运行链路按部门名、金额阈值、采购关键词或特定实体名称生成业务关系。
谓词、方向、条件和关系修订来自 LLM。代码存在技术校验、流程限制和建模约束；
其中后两类会限制其他材料的适用范围，因此不能把“没有采购业务硬编码”表述成
“任意材料均已通用验证”。前次“代码只校验”的表述需要明确这一边界。

## 已核实的判断与限制

| 类别 | 当前行为 | 对其他材料的影响 |
| --- | --- | --- |
| 技术校验 | ID 唯一、端点存在、证据定位、保留项与原输出相同、提示词/输入哈希匹配 | 不依赖具体业务领域，可复用。 |
| 流程限制 | 诊断问题最多 12 个，语义修订最多两轮，各阶段有 token 上限和一次技术重试 | 保障调用有界；不等于适用于任意长度和复杂度的输入。 |
| 固定实体集合 | 复核只修改关系；输出端点必须来自初始实体，不能新增、合并或改类型 | 初次遗漏或误分类的实体不能在本阶段修复，需另一个有来源支持的 LLM 实体修订阶段。 |
| 关系导向验收 | `answered` 必须引用关系，涉及的实体必须在这些关系的端点中 | 仅需属性、数值、日期或描述性事实即可回答的问题，不能直接以属性事实通过该契约；这是表示方式限制。 |
| 按行覆盖 | 每个非空原文行恰好纳入一组审计 | 证明审计记录覆盖输入行，不证明一行内多个语义都被正确理解。 |
| 溯源输入索引 | 对已有 source-type/path 汇总显式 target types，再校验模型声明与之匹配 | 属于对现有类型和链接的结构索引，不推导新实例关系；声明范围仍受已有图数据约束。 |
| 语言偏好 | v5 继承 v4 提示词中“名称、标签、定义使用材料的中文”的固定要求 | 没有按采购内容分支，但非中文材料可能被强制输出中文，尚未完全语言无关。 |
| 输入规模 | 单份 UTF-8 文本最多 32000 Unicode 字符，无自动切块、跨文档实体合并 | 分职责调用已实现，长文档分批抽取和合并尚未实现。 |

代码依据：

- `semantica/semantic_extract/candidate_coverage_stages.py`：预算、问题上限、
  `_plan`、`_patch`、`_audit` 和阶段流程。
- `semantica/semantic_extract/candidate_coverage.py::_validated_result`：关系、
  实体、行覆盖、任务回答引用校验。
- `semantica/ontology/candidate_provenance.py::_v4_provenance_prompt`：中文要求；
  `build_provenance_prompt` 继承该指令并压缩输入；声明仍由模型提供。
- `semantica/semantic_extract/candidate_profile.py::MAX_SOURCE_CHARS` 与 CLI
  导出的 limitations：单文档规模及无自动切块的边界。

提示词中的 A/B/C、条件、请求对象和时间义务示例不是可执行的业务分支，但带有制度/
流程材料的建模倾向；其他材料是否需要这些表达，应由原文和任务决定，不能套成必选关系。
`hasEvidence`、`rdf:type` 等固定标识属于现有 RDF/溯源表示协议，与采购角色或金额规则不同。

## 验证证据与不足

上一轮 673 项测试主要验证软件契约、错误拒绝、RDF 保留、离线重放和界面行为，
覆盖复核单测使用模拟模型响应；本次额外复跑无关系回答、未知端点等边界案例，5 项通过。
这些测试不能证明其他领域的真实模型抽取质量。新复核链路的真实模型验证主要集中在
`candidate_profile_v3.json` 的中文采购材料，不能据此宣称跨领域语义泛化已完成。

## 泛化前应处理和验证的事项

1. 输出语言随原文或显式任务配置，修订提示词时保留旧版本重放。
2. 区分可由属性事实回答的问题和需要关系端点回答的问题；语义选择由 LLM 给出，
   代码校验对应的输出契约，避免强迫无依据的关系化。
3. 初次抽取有遗漏时，通过独立 LLM 阶段提出实体修订，代码只做身份、证据和引用校验。
4. 长材料采用有边界的批次和来源定位，并验证跨段引用及合并；不单纯扩大一次输出额度。
5. 用不同领域、语言、属性为主、确实无关系和长文本的材料做真实模型评估，检查幻觉、
   遗漏、错误关系化及证据保持。评估结果与普通单元测试数量分开记录。
